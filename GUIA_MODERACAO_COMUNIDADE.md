# 🛡️ Guia de Moderação da Comunidade - Globe Memories

## Introdução

Este guia fornece diretrizes claras para manter o Globe Memories como uma comunidade autêntica de viajantes, livre de autopromoção comercial e comportamento inadequado.

---

## 📋 Categorias de Violações e Ações

### 1️⃣ NÍVEL 1: Infrações Menores (Aviso)

#### 🚩 Autopromoção Ligeira
**Exemplo:** Utilizador menciona subtilmente um link para o seu blog pessoal

**Ação:**
- Remover conteúdo
- Enviar mensagem privada educativa
- Primeira vez: Aviso
- Segunda vez: Aviso + Remoção
- Terceira vez: Suspensão 7 dias

#### 💬 Conteúdo Borderline
**Exemplo:** Publicação que parece quase comercial mas não completamente clara

**Ação:**
- Contactar utilizador para esclarecimento
- Se confirmado comercial: Remove + Aviso
- Se legítimo: Aprova com sugestão de edição

---

### 2️⃣ NÍVEL 2: Infrações Moderadas (Suspensão 7-30 dias)

#### 🏨 Promoção Comercial Clara
**Exemplos:**
- "Tenho um hostel em Lisboa, venham conhecer! Desconto 20% com este código"
- "Sou guia turístico profissional em Barcelona, reservas aqui: [link]"
- "Vendo cursos de fotografia de viagem por apenas 99€"

**Ação:**
- Remover IMEDIATAMENTE
- Notificar utilizador por email
- Suspensão: 7-14 dias (primeira vez)
- Se reincidência: 14-30 dias
- Terceira vez: Banimento permanente

#### 👥 Assédio Ligeiro
**Exemplos:**
- Comentários repetitivos inapropriados
- "Segue-me no Instagram!" (spam)
- Pedidos repetitivos de colaborações comerciais

**Ação:**
- Remover comentários
- Aviso privado
- Se continua: Suspensão 7 dias

---

### 3️⃣ NÍVEL 3: Infrações Graves (Banimento Imediato)

#### 🔴 Autopromoção Persistente
**Cenário:** Utilizador com múltiplas publicações comerciais apesar de avisos

**Ação:**
- Banimento IMEDIATO
- Email de notificação
- Bloqueio de email/username
- Possível relatório a autoridades (se atividade fraudulenta)

#### 😡 Assédio Grave
**Exemplos:**
- Assédio sexual
- Bullying persistente
- Ameaças
- Linguagem abusiva/racista

**Ação:**
- Banimento IMEDIATO
- Relatório a autoridades se necessário
- Remoção de todas as publicações

#### 🚨 Fraude/Roubo
**Exemplos:**
- Falsificação de identidade (fingir ser influencer/marca)
- Roubo de fotos de outros utilizadores
- Phishing ou scams

**Ação:**
- Banimento IMEDIATO
- Relatório a autoridades
- Notificação de vítimas

## 🔍 Exemplos Práticos de Moderação

### ✅ CASO 1: Publicação Legítima

**Publicação:**
```
"Estive em Marrakech durante 2 semanas e adorei! 
Este riad era incrível - muito acolhedor, pátio lindo com fonte, 
pequeno-almoço tradicional delicioso. O rapaz que gerencia é super simpático!
Ficava a 2 minutos da medina. Valeu cada euro! 
Alguém quer dicas sobre o resto da viagem?"
```

**Decisão:** ✅ APROVAR

**Razão:** É uma experiência genuína pessoal, menciona estabelecimento específico mas sem promoção comercial, sem link, sem código de desconto.

---

### ❌ CASO 2: Autopromoção Óbvia

**Publicação:**
```
"PROMOÇÃO ESPECIAL! 
Sou fotógrafo profissional de viagens. 
Posso documentar a tua viagem!
Preços especiais este mês apenas: [link para booking]
#viagem #fotografia #profissional"
```

**Decisão:** ❌ REMOVER + AVISO

**Razão:** É claramente uma promoção de serviço profissional. Violação clara dos Termos.

---

### ⚠️ CASO 3: Autopromoção Subtil

**Publicação:**
```
"A minha melhor experiência de viagem foi fazer um curso com o @TravelPhotoBR.
Aprendi tanto! Eles estão sempre recrutando guias se alguém se interessar.
Os fotógrafos que trabalham lá ganham bem!"
```

**Decisão:** ❌ REMOVER + AVISO (se contas estão relacionadas)

**Razão:** Utilizador está a promover disfarçadamente o próprio negócio/conhecido.

---

### ✅ CASO 4: Recomendação Genuína

**Publicação:**
```
"Recomendo MUITO este restaurante em Covilhã!
Comida tradicional portuguesa, donos super amáveis, 
acabámos a conversar horas com eles sobre a história local.
Preço muito justo. Voltava logo!"
```

**Decisão:** ✅ APROVAR

**Razão:** É uma recomendação genuína sem intenção comercial própria, sem links.

---

### ⚠️ CASO 5: Conteúdo Borderline

**Publicação:**
```
"Sou local em Cascais! 
Estas são as minhas melhores praias secretas...
[lista detalhada de praias]
Se precisarem de guia local para explorar, tenho disponibilidade!"
```

**Decisão:** ⚠️ CONTACTAR + POSSÍVEL REMOÇÃO

**Razão:** Última frase é suspeita (oferecendo serviço de guia). 
Contactar para esclarecimento antes de agir.

---

### 🔴 CASO 6: Assédio

**Comentário:**
```
"Olá linda! Qual é o teu Instagram? 
Quero conhecer-te melhor 😏"
```

**Publicação com múltiplos comentários assim de um utilizador**

**Decisão:** ⚠️ AVISO + REMOÇÃO (primeira vez)
                🔴 SUSPENSÃO (se continua)

**Razão:** Comportamento de assédio. Primeiro aviso, depois suspensão.

## 📊 Sistema de Pontos (Opcional)

Pode implementar um sistema de pontos de violação:

| Violação | Pontos | Ação |
|----------|--------|------|
| Autopromoção ligeira | 1 | Aviso |
| Autopromoção clara | 3 | Suspensão 7 dias |
| Assédio ligeiro | 2 | Aviso |
| Assédio grave | 5 | Banimento |
| Fraude | 10 | Banimento imediato |

**Sistema:**
- 1-2 pontos: Aviso
- 3-4 pontos: Suspensão 7 dias
- 5-7 pontos: Suspensão 14 dias
- 8+ pontos: Banimento permanente

## 🎯 Checklist do Moderador

Ao revisar uma denúncia:

- [ ] Leu a publicação/comentário completo?
- [ ] Verificou o histórico da conta (tem outras violações)?
- [ ] É uma violação clara ou borderline?
- [ ] A denúncia é legítima ou falsa?
- [ ] Qual é a ação apropriada segundo as guidelines?
- [ ] Escreveu mensagem clara e educativa?
- [ ] Documentou a decisão e motivo?
- [ ] Notificou o utilizador (se apropriado)?
- [ ] Removeu o conteúdo inapropriado?

## 📞 Escalação de Casos

### Quando Escalara para Administrador:

1. **Casos Legais:** Fraude, difamação, conteúdo ilegal
2. **Padrões de Assédio:** Múltiplas vítimas
3. **Dúvidas sobre Interpretação:** Caso não está claro
4. **Apelos de Banimento:** Utilizador contesta
5. **Atividade Suspeita:** Possível bot/spam automático

---

## 🔄 Revisão Periódica

Recomenda-se:
- **Semanal:** Revisar denúncias pendentes
- **Mensal:** Analisar tendências de violações
- **Trimestral:** Atualizar guidelines se necessário
- **Anual:** Treinar novos moderadores

---

## ✅ Princípio Fundamental

**"Moderação com propósito: Proteger a comunidade genuína enquanto permitimos 
a autenticidade genuína prosperar."**

Lembra-te: O objetivo é não apenas remover conteúdo inadequado, 
mas também **educar** os utilizadores sobre como contribuir 
positivamente para a comunidade!
